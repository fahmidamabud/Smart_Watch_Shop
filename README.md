# Smart_Watch_Shop

## 📋 Overview  
**Smart_Watch_Shop** is a web application (built with React + Vite + Tailwind CSS) that allows users to browse and purchase smart watches.  
This project demonstrates a modern front‑end setup, fast development environment with HMR, and clean styling using Tailwind CSS.

## 🎯 Features  
- Responsive product listing and detail pages  
- Tailwind CSS for all styling (no individual CSS files)  
- Vite for rapid development and optimized builds  
- React functional components + hooks  
- ESLint & Prettier (or configurations) for code consistency  
- Environment configuration via `.env` for sensitive keys or endpoints  
- (Optionally) Integration with a backend API / auth / cart logic — adjust depending on your full stack  

## 🛠️ Tech Stack  
- React  
- Vite  
- Tailwind CSS  
- JavaScript (ES6+)  
- ESLint / Prettier  
- Git & GitHub for version control  

## 🚀 Quick Setup & Installation  

<b> 1. Clone the repository </b>    
git clone https://github.com/fahmidamabud/Smart_Watch_Shop.git  
cd Smart_Watch_Shop  

<b> 2. Install dependencies </b>
 npm install

<b>3. Create .env file</b>
PORT=5000
MONGO_URI=your_mongodb_connection_string_here
JWT Secret Key JWT_SECRET=your_secret_key_here

<strong>(Optional)</strong> Cloudinary Config for Image Uploads
CLOUDINARY_CLOUD_NAME=your_cloud_name 
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret

<b>4. Run the project</b>
npm run dev
